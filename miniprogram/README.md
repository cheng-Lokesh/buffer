# 缓冲区微信小程序

> **状态：当前正式手机端。** 它与电脑官网共同服务同一个产品，但采用适合手机的原生四入口结构，不是官网页面的缩小版。

## 产品结构

四个入口固定为：现在、未来、条件、记录。

- **现在**：展示当前现金缓冲、所处区间、现金构成和结论依据。
- **未来**：展示 30、60、90 天现金轨迹，每个点位都能解释，并提供不修改现实的模拟。
- **条件**：在同一层修改现金起点、保留边界、最低日常支出、固定收支与已知未来事件。
- **记录**：只有现实变化时才记录，同时提供六套完整皮肤以及导出、导入和清空本机数据。

每个入口内部都采用固定视口场景，不要求用户上下滑动寻找内容：

- **现在**：位置、构成、依据，可点标签或左右滑动。
- **未来**：轨迹、点位、模拟，预测和现实明确分开。
- **条件**：基础、固定、未来事件，常用编辑都在一层完成。
- **记录**：记录、皮肤、数据，长记录使用上一页和下一页。

底部四入口负责切换产品区域，入口内部的场景负责切换同一问题的不同视角。两层导航都保持在当前手机视口内。

小程序本地优先运行，不要求登录，不连接云端，也不包含付费和商业化入口。所有判断只使用用户亲自确认的现实条件和变化。

## 本机检查

在仓库根目录运行：

```powershell
npm run test:miniprogram
npm run test:miniprogram:coverage
npm run verify:miniprogram
npm run test:no-scroll:browser
```

## 在微信开发者工具中查看

1. 安装并登录微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择本仓库的 `miniprogram` 文件夹。
4. 尚未配置正式 AppID 时，可使用当前 `touristappid` 在模拟器查看。
5. 需要手机扫码预览或提交审核时，把 `project.config.json` 中的 AppID 换成已注册的小程序 AppID，再点击“预览”。

## 数据边界

- 数据默认只保存在当前微信小程序本地。
- “导出备份”会把完整备份复制到剪贴板；用户可自行保存，或在另一设备的“记录”中导入。
- 可识别当前小程序备份，以及官网 schema 1 至 9 中的现金现实、变化记录和皮肤偏好。
- 这是明确的手动跨设备接力，不宣称实时同步。

正式公开前仍需在微信公众平台完成 AppID、类目、隐私保护指引、版本说明、真机检查和平台审核。这些平台手续不影响本地产品代码的完整性。
