# 图表查询交互简化

范围：只调整现在、未来的日期/余额查询，不改变现金计算、现实数据、导航或视觉基线。

## 用户路径

- 点击“查某天余额”，默认选中图表当前日期；今天、7天后、30天后直接定位。月份和日期下拉仍保留，只显示当前预测范围内的日期。
- 点击“查余额日期”，只展示金额查询。输入金额后查首次不高于该金额的日期，不意味着余额必须恰好等于输入。
- 选择后同时更新图表、详情和面板中的日期/余额。面板保持打开，避免重复打开查询；支持关闭按钮和 Escape，并归还焦点。
- 手机采用底部面板，保留原图表，查询不会写入 Reality。
