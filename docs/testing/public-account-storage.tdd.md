## 边界

用户 JWT 只能选择平台确认的本人身份，客户端 owner、服务账号、管理员角色、外部环境、过期会话被拒绝。资料不落盘、不回传个人信息，关闭重定向、限制响应大小及超时；无密码或服务账号回退。

SQL 在 PGlite 的实际 PostgreSQL 引擎执行：默认空配置拒绝；匿名没有 RPC 权限，普通身份没有私有表权限；存储由 auth.uid() 选择，无 owner 参数。写入数据与幂等回执在一个事务完成；失败回滚、CAS冲突、重复重试、删除世代和重装不重置均验证。服务账号即使持有后台键也不能读写财务数据。

后台键只是服务端领域校验防绕过门，不授予任意账号选择权；初始未生成或配置。私有表保存当前快照与回执，删除清除此前的财务回执，仅保留删除回执和世代。不能保证清除供应商备份，隐私说明及真实删除策略仍需验收。

RPC 存储适配用已验证用户自己的 bearer 调用三个固定接口；不使用登录保护服务会话。乐观事务冲突最多重试三次，纯领域回调重新读取版本；网络调用不持有数据库锁。SQL 与适配器测试分别验证真实本地 SQL 和合成 HTTP 返回，没有把替身当腾讯云实测，也未验证真实云端并发。
