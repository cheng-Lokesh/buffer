# 公开服务阶段一：账号同步事务边界

日期：2026-10-08。依据 `docs/PUBLIC_SERVICE_PRD.md`，本文件是开发证据，不是需求来源或生产上线证据。

## 用户路径与边界

- 经过真实账号验证后，只读取该账号的状态。
- 本人确认的操作以版本号提交，网络重试不重复计入；并发冲突不覆盖原状态。
- 导入本机旧数据必须单独批准且云端为空；云端已有数据时拒绝静默替换。
- 删除推进世代，旧设备队列不能复活已删除的数据。

## 实现

`server/account-sync-service.js` 提供服务器处理器工厂，强制依赖真实身份验证、持久化账号事务和领域确认校验三个适配器。没有任何默认假登录、内存生产数据库或直写快照。模块尚未挂载到线上或本地服务器，网页和小程序仍使用原本机数据。

事务适配器必须在同一原子事务内提交快照与幂等回执，并提供账号级串行化/版本检查。单元测试内存实现仅为标记清楚的测试夹具，不证明生产数据库事务正确。领域适配器仍须接入现有候选确认校验和真实迁移验证，不能直接返回未经验证的客户端 JSON。身份适配器须验证实际控制权与会话撤销；HTTP 挂载须补 Origin/CSRF、请求限流等实际登录方式需要的防护。
