# Buffer 当前阶段前端基线

## 结论

`site/` 是 Buffer 当前阶段唯一前端基线。

- 可编辑视觉源码：`site/index.src.html`
- 构建交付文件：`site/index.html`
- 背景动效：`site/starfield-background.js`
- 当前素材：`site/assets/`
- 本地服务：`site/server.py`
- 构建入口：`site/build_index.py`

根目录 `src/` 下的 Vite/React 页面、历史截图、旧版本实现、其他工作区和外部原型都不是当前阶段的视觉起点。

## 已确认的视觉基础

后续优化必须保留并延续以下整体方向：

1. 深蓝夜空与山景全景构成主要氛围。
2. 左侧固定品牌与四空间导航保持清晰稳定。
3. 现在、未来、条件、记录继续使用当前信息结构。
4. 数据界面保持冷静、克制、可信，发光与透明层级不得喧宾夺主。
5. 当前中文字体组合、手写文案、侧栏影像和不规则星空动效属于整体审美的一部分。
6. 现实、预计和模拟继续通过文字、线型与颜色共同区分。

## 后续优化规则

- 所有可见修改先改 `site/index.src.html`，再运行 `python site/build_index.py` 生成 `site/index.html`。
- 优先做增量优化，例如可读性、空间关系、响应式、无障碍、性能与真实交互摩擦。
- 未经用户明确确认，不得整体重做、切换视觉风格、替换主要素材、重新定义导航或恢复旧产品形态。
- 不得把根目录 Vite 页面或其他工作区内容复制回来覆盖 `site/`。
- 涉及视觉的改动必须同时检查桌面和手机，并将自动化验证与用户视觉验收分开陈述。
- 页面优化不得改变 Reality、Forecast、Scenario 的产品边界，也不得加入指导、催促或建议。
