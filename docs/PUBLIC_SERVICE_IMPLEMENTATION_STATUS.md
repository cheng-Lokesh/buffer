## 2026-10-08 微信认证服务候选

已实现 `wechat-login-service.js`：只接受微信授权码，调用官方 code2Session，丢弃 session_key/unionid；身份由服务端验证后派生，客户端不能选择账号或直接绑定另一身份。失败脱敏，禁止缓存，严格限制方法、类型及请求体大小。

已实现 `cloudbase-ticket-signer.js`：按 CloudBase PG 自定义登录协议，以 RSA 密钥签发五分钟凭证。只接受规定格式的微信派生身份，拒绝管理员和任意账号；避免浏览器 SDK 初始化产生的 BroadcastChannel 生命周期问题。测试使用临时生成的 RSA 夹具，不是本人的真实凭据。

已实现 `postgres-login-guard.js` 和 `sql/001-login-guard.sql`：专用私有表、事务锁、每日总请求上限、每分钟网络来源上限、授权码摘要唯一约束。上限必须显式配置，未知网络来源/缺少数据库不允许请求。SQL 尚未在真实环境执行；查询替身测试不代表 PostgreSQL 并发或权限验收。

`wechat-login-runtime.js` 已完成三个模块的服务端组合；没有自动挂载公网端点，没有假登录或内存存储回退。真实平台确认 ticket、统一网页/微信身份绑定、页面登录联动和持久化同步仍未完成。
