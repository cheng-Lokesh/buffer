# 开发资源创建指引：不自动扣费

核查日期：2026-10-08。用户明确暂无正式 AppID/CloudBase 环境，要求指导创建且不开自动扣费。这是操作指引与成本边界，不是资源创建或上线证据。

## 先说明免费边界

腾讯云当前免费体验规则：体验环境不支持自动续费、不能开启按量付费；体验环境用于开发，不是永久免费的生产服务。正式发布微信小程序后，体验环境到期日调整为上线后第15天，长期使用需要重新处理生产费用。不要将旧促销或新手“首月免费”教程当作当前终身免费承诺。

## 1. 微信小程序 AppID

1. 打开 https://mp.weixin.qq.com/，选择“立即注册”，账号类型选择“小程序”。
2. 使用可注册的邮箱，按平台提示激活。
3. 按真实运营主体填写个人/企业信息，不为了绕过平台限制虚报主体。身份信息和扫码验证只在官方页面处理，不发送给开发助手。
4. 若出现认证/付款，先停下，说明页面要求和金额；不要付款。注册、主体、服务类目和正式发布要求不一定相同，不能保证注册成功就可以免费发布。
5. 获得账号后，在“开发管理 → 开发设置”找到 AppID；后台菜单若变化，用“AppID”字段定位。
6. 仅提供 AppID，不发送 AppSecret、上传密钥或身份证件。后续必须核对实际主体、允许服务类目、隐私和备案/平台发布要求，不以产品免责声明替代。

## 2. 开发用 CloudBase

1. 打开 https://console.cloud.tencent.com/tcb，登录现有腾讯云账号。
2. 找“新建环境/免费体验”入口。若要求服务角色授权，阅读官方授权用途后由账号本人决定；不要把登录腾讯云或 EdgeOne 部署当作已开通 CloudBase。
3. 环境名称填写 `buffer-dev`，选择中国大陆可用地域，记录实际地域。
4. 仅选明确的免费体验环境；只有最终金额为0元、自动续费关闭、超限按量付费未开启时，才可确认创建。不购买“个人版/平台版”来代替消失的免费入口。
5. 若只有付费方案、扣费授权或无法关闭续费，就停在该页面，提供遮去账号身份的截图。不要充值、绑定扣款、销毁已有环境来获取免费资格。
6. 等待环境为正常状态，复制环境 ID，记录套餐类型、地域、到期日、续费/超限设置。只提供环境 ID 和地域，不发送密钥。

现有网站继续由 EdgeOne 托管，无需为这一步另行开通 CloudBase 网站托管。先只建开发环境，不导入真实现金数据、不发布小程序。真实环境到位后，再验证身份、存储事务、访问隔离和成本控制；平台费与模型费是不同账单，免费环境不表示原解析供应商免费。
