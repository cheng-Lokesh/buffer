# 本机账单观察：私有试用范围

2026-09-24 本人明确授权在现有 Buffer 四空间内实施这项能力。正式 Reality 合同仍是 V12.1；这里是被单独批准、仅供本人在密码保护的网站试用的范围例外，不是公开产品发布，也不保证法律合规。

## 已实施

- 在「记录」单独打开「本机账单」，选择本人自行导出的 CSV。需有可识别的日期、收支和金额列；不采集支付平台登录信息。
- 文件在浏览器本地解析，原文件和明细不发送到 Buffer、腾讯云函数或模型。保留在内存里的仅是日期、金额、方向、有限类别、固定来源标签、核对状态和本次会话标识；姓名、商户、账号、流水号及备注原文被丢弃。
- 所有交易初始为待核对。失败、退款、资金转移、未知方向、字段错误和疑似重复不能用批量按钮计入观察。本人可逐笔计入、排除、重新核对和删除，亦可清空整批。
- 「现在」保留原四张现金卡、中央结论及右侧信息。仅在本次导入后，原底部六卡区域可切换「预计节点／账单观察」；观察统计明确限于导入文件和已核对记录。
- 账单数据只在当前页面会话的 JavaScript 内存里，刷新、关页后消失；不写现有 localStorage、备份或 Reality。导入与核对不会更改现金余额或未来预测。

## 当前未提供

- XLSX、PDF、截图/OCR、银行同步、支付平台接口、自动拉取；不同平台 CSV 表头可能需要适配。没有用户真实账单样本，因此不能声称已支持所有微信/支付宝/银行导出格式。
- 加密本机长期存储、跨设备账单备份、自动分类、消费异常评判、从账单自动更改 Reality 或预测。
- 公开注册与公开使用。若以后开放，须按实际运营主体、部署地点、数据流完成隐私告知、备案及安全核查；本次私有技术测试不能替代该核查。

## 验证门槛

`node --test test/bill-observation.test.js`、`node --test test/bill-site-journey.test.cjs`、现有站点及安全回归、桌面与手机渲染、发布包检查。合成测试文件只用于验证代码，不是本人真实使用证据。正式接收仍需本人用自行脱敏的真实导出文件在私有站点核对支持情况。
